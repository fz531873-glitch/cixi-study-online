# 2025 年上午卷首批 12 道样板题逐项讲解方案（修订版）

## 一、总体设计原则

1. **知识卡关联与逐项讲解解耦**：保留现有 `links`（知识卡与题目的多对多关联）用于「学后练习」和按考点找题；逐项讲解数据按 `(question_id, version)` 组织，绑定具体题目版本，避免知识卡修订或题目版本升级后讲解错位。

2. **严格的权限与时机隔离**：

   * `GET /api/bootstrap` 继续通过 `stripAnswer` 隐藏 `answer`、`direct`、`analysis`、`note`、`references` 及逐项讲解数据，确保作答前不泄露任何答案线索。

   * 逐项讲解仅在用户提交作答后（`POST /api/attempt` 返回及 `GET /api/attempt/:id` 读取 `attempt.snapshot`）或主动点击「不会，看解析」查看解析时（`GET /api/editor/question/:id`）提供。

   * 重新打开旧作答时，继续读取当时保存在 `attempt.snapshot` 中的题目版本与解析依据。

## 三、核心机制说明

### 1. 如何记录一个选项或陈述的判断、依据及其具体使用的知识规则

每道题的逐项讲解按 `(question_id, version)` 建索引，内部由 `items` 数组记录每个选项（`A`/`B`/`C`/`D`）或组合陈述（`①`/`②`/`③`/`④`）。每条依据除写明理由外，必须附带可回查的 `source_ref`（资料编号、资料名称、页码与定位处）：

```json
{
  "question_id": 13,
  "version": 1,
  "stem_polarity": "选正确",
  "items": [
    {
      "key": "①",
      "statement_truth": false,
      "matches_stem": false,
      "verdict": "排除",
      "basis": "全国人大常委会审议《生态环境法典（草案）》行使的是国家立法权，而非决定权。",
      "source_ref": {
        "question_material": { "id": 8, "name": "2025年9月21日上午余姚、慈溪、象山、宁海事业单位试卷.pdf", "page": 3, "location": "第13题陈述①" },
        "analysis_material": { "id": 7, "name": "2025年9月21日上午余姚、慈溪、象山、宁海事业单位答案及解析.pdf", "page": 4, "location": "第13题解析第1句" }
      },
      "rule_id": "RULE-LAW-NPC-LEGISLATION-02",
      "rule_statement": "制定、修改和审议法律草案属于全国人大及其常委会的立法权，不能与决定权混淆。",
      "knowledge_id": 20003
    },
    {
      "key": "②",
      "statement_truth": true,
      "matches_stem": true,
      "verdict": "入选",
      "basis": "党的二十届三中全会提出编纂生态环境法典，体现党领导立法、推进法治化。",
      "source_ref": {
        "question_material": { "id": 8, "name": "2025年9月21日上午余姚、慈溪、象山、宁海事业单位试卷.pdf", "page": 3, "location": "第13题陈述②" },
        "analysis_material": { "id": 7, "name": "2025年9月21日上午余姚、慈溪、象山、宁海事业单位答案及解析.pdf", "page": 4, "location": "第13题解析第2句" }

      "rule_id": "RULE-POL-PARTY-LAW-01",

      "knowledge_id": null
    }
  ]
}
```

* **判断（`statement_truth` / `matches_stem` / `verdict`）**：先记录陈述本身是否成立（允许证据不足时留空 `null`），再记录是否符合题干设问。

* **依据与定位（`basis` + `source_ref`）**：写明判断理由，并给出原题与原解析的资料号、页码及具体条目位置，方便逐页复核。

* **具体知识规则（`rule_id` + `rule_statement`）**：精确到可独立判别对错的单一规则句；`knowledge_id` 仅保留作找题索引，若现有知识卡未覆盖该规则（如第 8 题），直接标记为「知识卡缺口」。

### 2. 如何处理「选错误的一项」、多选漏选与争议题（含第 13 题、第 16 题演示）

#### （1）「选错误的一项」（如第 8 题、第 18 题）

* 严格拆开 `statement_truth`（该选项陈述本身是否正确）与 `matches_stem`（是否满足「错误的是」设问）。

* **用户误选了本身正确的选项**（例如第 18 题选了 `A`）：先肯定 `A` 的陈述本身符合会议纪要写作规范（`statement_truth: true`），再点明「本题问的是**错误的一项**」，因此 `A` 不应选；随后指出 `D` 把「会议纪要」混同于「会议记录」，才是本题要找的错误项。

#### （2）多选与漏选（如第 26 题，参考答案 `BD`）

* 对用户作答集合 $U$ 与参考答案集合 $A$ 做集合差：

  * **漏选（$A \setminus U$）**：重点展示漏选项的入选依据（例如选 `B` 漏 `D` 时，提示「`B` 正确，但漏选 `D`：代表履职积分制与乡村治理积分制结合，直接丰富了选民联系形式」）。

  * **错选（$U \setminus A$）**：先给出错选项的排除规则（例如误选 `A` 时，指出「基层治理领导核心是党组织，不是人大」）。

  * **全对（$U = A$）**：展示简析 + 可展开的逐项规则对照，不重复堆砌长段文字。

#### （3）争议题的存疑状态（以第 16 题 `id=16` 为验收样例）

* 对证据不足或存在法律适用分歧的选项/陈述，允许 `statement_truth` 与 `matches_stem` 留空（`null`），`verdict` 设为 `"存疑"`，并通过 `dispute_note` 保留分歧说明与权威出处链接，不强行用布尔值硬判：

### 3. 如何确认两道题在考同一条规则

采用「**知识卡候选初筛 + 规则判别条件核对**」两步法：

1. **同卡列为候选**：凡在 `links` 中挂载同一张 `knowledge_id` 的题目，先列为「同规则候选对」。
2. **核对实际要求的判断**：逐一比对两题关键选项/陈述的 `rule_id` 与设问判别动作：
   * **正例（同一规则，可作换题验收）**：**2025 年上午卷第 17 题（`id=17`）** 与 **2019 年 7 月象山事业单位第 25 题（`id=19025`）**。两题均对应知识卡 `k_id=20070`（公文文种——平行文与函的适用），且实际要求做出的判断完全一致——「平级或不相隶属机关之间商洽事项（前者为一般公文行文场景，后者为公安局向学校借用场馆）适用**函**」，均绑定同一 `rule_id: RULE-DOC-LETTER-01`。
   * **反例（同卡但考不同规则，不可合并）**：**2024 年下午卷第 7 题（`id=24107`）** 与 **2025 年上午卷第 13 题①（`id=13`）**。两题虽均挂载在知识卡 `k_id=20003`（国家立法权的行使机关）下，但 `24107` 考「**谁行使国家立法权**（全国人大及其常委会）」，而 `13`① 考「**审议法律草案体现哪种职权**（立法权而非决定权）」。两者保留同卡找题关联，但**赋予不同 `rule_id`**，不把它们当成同一条规则的换题复测。
