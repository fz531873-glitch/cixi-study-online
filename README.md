# 慈溪备考 · 第一版

个人公基学习网页：知识回忆、学后真题、逐题直解、错因与复习、跨设备学习位置、内容纠错与版本记录、备份恢复。

正式地址和发布验证见[上线交付.md](上线交付.md)。采用本人登录访问，使用与发布账号对应的ChatGPT账号；学习记录保存在云端数据库，不需要原电脑保持运行。

## 资料

- 345道客观题，196条知识内容，12份原始PDF。
- 115题逐题整理直解；其余230题摘取原解析判断依据并注明待复核。
- 15道争议题显式标记并排除掌握统计；其他待核对题仍需结合原资料使用。
- `data/catalog.json`保留题干、参考答案、原解析、直解、出处与版本。
- `data/explanation-overrides.json`保存逐题整理与纠错内容；`data/解析核对清单.md`可逐题阅读。
- “宪法与立法权限”是首个小单元模块；其他183条原文笔记仍按页组织。

## 使用

首页继续学习或选择到期复习。知识卡先阅读，点击“开始回忆”隐藏原文，展开核对后记录自评，再进入当前知识的已确认真题。无已确认关联时会提示题库暂未覆盖。

答题后先看“直接点明”，再按需展开完整原解析和PDF原页。新题需要重新确认把握程度。争议题只与原资料答案对照，不影响掌握统计。

“资料纠错”可修改题干、题型、参考答案、直解、原解析、知识正文、来源页码与核对状态。每次修订填写依据；历史作答保留当时的题目和判定快照。

“学习记录”可下载JSON备份并恢复，恢复前会先下载当前备份。JSON包含学习记录和资料文本，PDF另行保存。单份恢复请求限8MB。

## 本地维护

本机已安装Node 24。依赖仅安装于本项目；不需要更改全局Python环境。

```powershell
npm run dev -- --port 5173 --hostname 127.0.0.1
node --test tests/core.test.ts
node node_modules/typescript/bin/tsc --noEmit
npm run build
```

本地数据库位于忽略目录`.wrangler/state`，与正式云端数据库分开；本地登录仅供开发预览，生产由Sites平台认证。数据库结构在`db/schema.ts`，迁移记录在`drizzle/`；已应用的迁移文件不可改写。

重新生成资料使用`D:\python\python.exe scripts/prepare-catalog.py`，读取旧项目及`D:\事业编`中的指定PDF，不改写旧数据库。重新发布通过Sites官方源代码与构建产物流程，复用`.openai/hosting.json`中的站点ID。

完整验收方法、证据和未检查范围见[验收记录_20261103.md](验收记录_20261103.md)。
